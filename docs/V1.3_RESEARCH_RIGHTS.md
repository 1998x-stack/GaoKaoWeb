## 3. 来源分层：发布/AI 可用性矩阵

| source tier | 页面可公开 | 保存原文 | 下载 | 衍生改编 | 对外部 LLM 提供正文 |
|---|---|---|---|---|---|
| S0 official_link_only | 仅本站原创索引元数据+官方链接 | 否 | 跳原站 | 否 | 否 |
| S1 verified_owner_authored | 经确认并获作者许可后 | 根据明示授权 | 根据明示授权 | 根据明示授权 | 须有 AI 处理授权 |
| S2 licensed_OER | 按单条许可 | 按许可 | 按许可 | 受 NC/ND/SA 限制 | 需许可+服务条款审核 |
| S3 internal_pending | 不公开 | 内部受控留存的合法材料 | 否 | 否 | 否 |
| S4 retired/revoked | 404/下架与说明 | 按合规策略处置 | 否 | 否 | 否 |

严禁将 S0 伪装成 S1/S2；任何用户上传的题目不是自动授权。各字段的授权行为必须逐项评估：链接、display_full, host_file, distribute, modify, translation, create_embeddings, send_to_llm。

## 4. 2026 高考地域/年份门控

- examYear（必填），provinceCodes（必填或明确 unknown），examScheme（national-I / national-II / provincial / school-made / unknown），paperName，subjectName，examDate。
- “全国一卷适用省份”只按**对应年份证据**维护；不得依赖最新年份规则推算以往卷别。
- 官方新闻/评析 ≠ 官方题干/标准答案；需为不同 resourceKind。
- “来源真实” ≠ “题目正确” ≠ “可转载” ≠ “适用于学生所在地”；四种独立结论。

## 6. 风险日志

- R01: 复制受版权保护的官方试卷/商业题库 => P0 阻断，外链默认。
- R02: 地区和年度映射误导 => P0 阻断，未证实范围不展示“适用”。
- R03: 错题/多解/错答案 => P0 审题门槛、数值检验+第二位复审。
- R04: 解析图片/数学公式 OCR 丢条件 => P1 数学表达式一致性校验、截图人工对照。
- R05: AI 把候选页码当正式证据 => P0 候选来源不可进入可引用索引。
- R06: 未成年人作答数据/教师班级数据泄露 => 默认本地、不上传；后台支持时最小化、访问控制、保留策略。
- R07: OER 使用范围冲突（NC/SA/ND）=> 明确商业性和衍生用途、许可证据存档。
- R08: 反爬/登录绕过 => 禁止；仅公开许可 API 或人工采集元数据。
