## 2. 拟构建的专题地图（教师审核前的建议）

1. 函数与导数
2. 圆锥曲线
3. 三角函数
4. 概率统计

教学顺序建议：概念 → 多方法解题 → 分类讨论 → 极值/综合分析。

每个专题进入未来题库前必须填写：适用课程标准版本、对应知识 ID（目前需人工审核）、题型及能力目标、地区/年份、合法题目来源、审核人和审核日期。

## 3. 拟开发的题目与资源

- 例题/练习：围绕 含参导数、圆锥曲线、三角恒等与求解 建立小批量自编或获授权题目，并给出完整答案和教学讲解。
- 备课：教学目标、先修诊断、示例变式、常见误区、课堂检测、作业与复盘。
- 学生路线：先修 → 知识讲解 → 经审定的练习 → 迁移/检测 → 间隔复习；“阅读”不等于“掌握”。
- 资源卡：sourceId、contentKind、rightsGrant、subjectId、year、provinceCodes、examScheme、topicIds、pedagogyReview。

**风险提示：** 2019 历史理科考纲不是现行普遍考试方案；题型卷别需核验。

## 4. 正式发布审核

1. 先证实原站内容是官方“原卷”还是“专家评析/新闻”，不要混用。
2. 不取得书面许可或明确开放授权时，只发布原创元数据与链接，不托管题干、解析或课件图片。
3. 对所有公式、文本、图示、答案进行独立教研审核；自动标签只作为候选。
4. 省份、年份与课程方案无法确认时保持未核验，不提供“适用于本年度”标签。
5. 试题撤回/纠错应同步处理教学包、练习与学习路线。
