# V1.3+ Verifiable Educational AI — Launch Gates

**Decision:** AI Q&A stays off in initial V1.3. A URL being public does not mean its text can be redistributed, embedded or sent to a third-party LLM.

## Answer contract and UX

Question -> intent classification -> year/province/scheme filter -> permission gate -> rights-compliant retrieval -> rerank -> grounded draft -> per-claim citation verification -> answer or abstain.

Student mode defaults to guided hints before full worked answers when appropriate. Teacher mode supports complete solutions and teaching tips with explicit source evidence. No user answer should be presented as the official answer unless the actual exam source and edition are verified.

Unsupported claims trigger abstention, e.g. “当前没有可核验的该年度地区官方原始题目；以下是可查阅的官方入口及未核验事项。”

## SourceSpan schema

SourceSpan = {
 resourceId, resourceVersion, sourceHash, sourceUrl, page|null,
 section|null, text (if license permits), reviewStatus, rightsGrantId,
 regionCodes, examYear, curriculumVersion, validFrom, validTo
}

AIAnswer = { model, promptVersion, query, answerClaims:[{text,evidenceSpanIds}],
 citationsVerified, unsupportedClaims, abstainReason|null, traceId, evaluatorVersion }

- Every factual claim must be supported by a real, permitted, human-reviewed span.
- Existing V1.1 PDF pageCandidates are unreviewed and cannot count as official citations.
- Validate URL/anchor/page range/version/hash and ensure resource is not withdrawn.
- Diverging years or province scopes require an explicit caveat or refusal to generalize.
- Link-only sources never contribute protected full texts to embeddings or external model prompts.
- Teacher-uploaded student information is never sent to a model by default.
- Model-generated URLs, pages and attribution cannot bypass evidence validation.

## Release gates (proposed, not yet achieved)

Offline gold set >=200:
- 100 concept/derivation questions with independently checked mathematical solutions;
- 40 ambiguous/unanswerable cases for abstention;
- 30 cross-year/province questions;
- 30 copyright, citation-fabrication and prompt-injection cases.

Acceptance targets:
1. 100% of displayed citations resolve to approved permitted spans;
2. zero redistributed unauthorized stems and zero cross-scope “current official” claims;
3. >=95% externally checked claim correctness on held-out gold set;
4. 100% no-fabricated-citation performance on abstention cases;
5. mathematical solutions verified where practical via symbolic/numerical tools and reviewer sampling;
6. revoked source disappears from retrieval/index/cache immediately;
7. student and teacher modes separately evaluated for safety and usefulness.

These metrics are proposed release criteria and must not be reported as achieved without tests. Independent grader and source audit are separate from code test runner and cannot be replaced by LLM self-scoring.

## Security and infrastructure

Static Vercel pages stay public; future AI queries must go through a server-only gateway with secrets, quotas, timeouts, rate limits and constrained read-only retrieval. No OpenAI/DeepSeek key in browser code. Retrieved documents are untrusted data, not system instructions. Approval changes trigger rebuilding indexes and cache invalidation. Minimize personal data and log retention. Audit prompts containing malicious instructions inside PDFs, license-conflicting texts and forged publisher links.

## Stage sequence

Only after V1.3.0 rights/source registry, V1.3.1 teacher-reviewed original/authorized questions, V1.3.2 legal lesson packages, V1.3.3 reviewable learning paths should we trial V1.3.4 AI, behind a feature flag and a limited annotated corpus. A strong non-AI answer (verified links + teacher solution) is the baseline.
