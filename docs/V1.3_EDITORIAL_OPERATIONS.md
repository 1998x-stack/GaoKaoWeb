# V1.3 教学资源编辑 / 审核 / 下架操作手册

状态：**未来上线流程**。当前代码仅有 V1.3 source-candidates.json、rights-policy.mjs 与单测；无后台、无多人审批审计数据库。以下检查不能被标记为“已由系统执行”。

## 1. 角色与权限（拟议）

| 角色 | 可以做 | 不可以做 |
|---|---|---|
| 资料收集者 | 提交外链元数据、来源截图链接、版权待核验信息 | 自行宣布原卷或全文授权 |
| 科目编辑 | 建立题型/知识映射候选、核对题干和答案 | 自审自发高风险题目 |
| 版权审查者 | 检查权利人、许可条款、有效范围和再分发权 | 只凭“教育用途”通过全部授权 |
| 数学复核者 | 校核公式、定义域、答案、题型和教学适用性 | 以 AI 自评取代独立审核 |
| 发布管理员 | 检查所有门槛、发布版本、处理撤回 | 在版权撤回后恢复旧缓存全文 |
| 安全审核者 | 检查私有学生数据、访问边界和 AI 索引内容 | 以公开 repo 托管学生个人资料 |

## 2. 可复用状态流

外链元数据：
DISCOVERED → URL_CHECKED → CHARACTERIZED → METADATA_REVIEWED → LINK_ONLY_PUBLISHED → WITHDRAWN

全文习题：
DISCOVERED → RIGHTS_REVIEWED → CONTENT_TRANSCRIBED → MATH_SOLUTION_REVIEWED → PEDAGOGY_REVIEWED → APPROVED → PUBLISHED → CORRECTED / WITHDRAWN

当前实现中 workflowStatus 仅有 candidate / metadata_reviewed / rights_reviewed / pedagogy_reviewed / published / withdrawn，**不是上面完整工作流引擎**。新增实现需有状态迁移合同和不可绕过的多维度准入检查。

## 3. 审核表（必须填写而不是单个勾选）

| 维度 | 需记录的可追溯证据 |
|---|---|
| 来源 | 访问链接、发布主体、标题、发布日期、访问日期、文件或内容摘要 |
| 真实性 | 是试卷原卷、试题评析、新闻、课程标准还是原创题 |
| 适用范围 | examYear、province、scheme、课程版本、不确定状态 |
| 权利 | 许可持有人、授权协议、授权动作（display/distribute/adapt/AI）、期限、署名/SA/NC/ND、第三方素材 |
| 教学 | 答案、推导、边界条件、第二解法、教材范围、题型归类、易错点 |
| 技术 | PDF 页面及数学公式、可访问性、生成/导出路径、构建回归 |
| 审核 | 审核角色、日期、证据哈希、驳回或批准原因、再审触发 |

## 4. 不同类型资料如何处理

**官方原卷链接**：如果确实存在并能证实身份，可公开元数据和外链；未经权利审核不托管题目全文、PDF 或配图。

**官方试卷评析**：kind 必须是 exam_review；不能仅更改字段就称为官方原卷。可以写本站原创的简短索引摘要，不应复制整篇评析。

**教师原创题**：独立声明权属与允许使用范围；验证图像和排版素材，评审答案；并非所有教师上传内容都归平台拥有。

**开放许可内容**：核对具体版本、许可证及其 NC/ND/SA 条件，保留许可链接和来源快照。许可不自动覆盖未授权的第三方插图。

**AI 生成草稿**：永远以 draft 状态进入，明确可能错误、不含外部来源版权凭证，必须人工审核再入库。

## 5. 发布工作单（PR 模板）

~~~yaml
resourceId: pending
contentType: exam_review | authored_question | licensed_question
origin:
  sourceUrl: https://example.invalid/
  issuer: pending
  publishedAt: null
verification:
  artifactType: source_page
  officialBinaryMatched: false
  scopeReviewed: false
rights:
  holder: pending
  grantedActions: []
  evidenceUrl: null
  expiry: null
pedagogy:
  answerReviewed: false
  topicMappingsReviewed: false
reviewers:
  metadata: pending
  rights: pending
  subject: pending
release:
  allowPublicMetadata: false
  allowHostedFullText: false
  allowExport: false
  allowAI: false
~~~

此工作单是**审核填写示意，不是合法内容记录或当前 schema**。example.invalid 是占位符，不能随 PR 发布。

## 6. 纠错、撤回与事件日志

1. 接到投诉/撤回即标记 blocked；对包含全文的页面、下载、离线缓存、搜索与 AI 索引设置阻断，记录发生时间。
2. 索引和静态页面重新构建，缓存失效；保存权利证据但处理方式遵从适用法律、协议和隐私规则。
3. 如需更正，创建新资源版本，附修复差异、影响范围、第二复核结果及回滚预案。
4. 回滚前检查当时权利有效性和新撤回记录；不能用“旧构建可用”作为继续发布的理由。
5. 监测与处理时效需要单独定义 SLO，不应在系统尚未实现时声称可自动瞬时下架。

## 7. 独立审核运行

当前命令：
- npm run check:v13 → 5 条种子候选保持 link-only、且没有未经审核题干
- npm run verify → 构建与测试
- npm run audit:pdf → 使用 Poppler 重新核验历史 PDF 缓存

未来完整审核器需增加真实版权证明文件验证、审核事件签名、过期授权扫描、下载/AI 传播权限、政策变更触发的复核与纠错反馈。

详细数据定义见 [V1.3_DATA_DICTIONARY.md](V1.3_DATA_DICTIONARY.md)。
