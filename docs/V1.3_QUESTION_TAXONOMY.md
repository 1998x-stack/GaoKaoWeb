# V1.3 数学题型与专题标注标准

> 当前 content/v1.3/mathematics-taxonomy.json 是**拟议分类草案**；专题 topicIds 均为空，需要教师确认与 V1.2 正确节点映射。高中数学应避免把旧理科/文科两个目录直接当作新高考课程标准。

## 1. 分类的六个正交维度

| 维度 | 示例 | 不可混淆 |
|---|---|---|
| 试题形式 | 单选、多选、填空、解答、证明、建模 | 与数学难度不同 |
| 知识领域 | 函数、三角、数列、立体几何、概率、圆锥曲线 | 与卷别/年份无关 |
| 解题策略 | 分类讨论、数形结合、构造、换元、韦达、导数 | 一题可多策略 |
| 能力目标 | 数学抽象、逻辑推理、数学建模、直观想象、数学运算、数据分析 | 与每道题的实际测量分开 |
| 常见错误 | 漏条件、符号错误、定义域、证明跳步、计算错 | 需有审核过的典型解答 |
| 难度来源 | 未评、教师估计、真实作答统计 | **禁止用模型预估伪称实测难度** |

每个标签需记录 code、中文名、定义、互斥/可多选规则、示例、审核者与版本；算法自动预测标记 suggestion_unreviewed。

## 2. 三个数学试点专题

### A. 导数与函数性质

目标链：函数图像与导数符号 → 单调区间 → 极值/最值 → 参数分类讨论 → 不等式或函数零点。关键易错点：开闭区间、导数不存在点、参数分界、局部极值与整体最大最小不同。

题型建议：概念判断、函数单调区间、含参极值、函数零点与不等式。训练只使用有来源、正确答案和授权的原创题目。

### B. 圆锥曲线与解析几何

目标链：定义与方程 → 直线与曲线联立 → 判别式及根的条件 → 韦达定理 → 弦长/中点/面积 → 定点、定值及最值。
易错点：求解前必须检查存在条件、参数化退化、斜率不存在情形、分母为零、几何合法性。

题型：焦点弦、相交弦、定点/定值、面积优化、曲线族。方法标签与几何条件需要两位独立校核者抽样复核。

### C. 三角函数与解三角形

目标链：角与弧度 → 基本恒等式 → 和差、倍角、辅助角 → 图像变换、周期与单调区间 → 正弦/余弦定理 → 实际建模。
易错点：角度/弧度混用、周期、值域条件、三角形解的多解情况。

## 3. 标注工作流

1. 教师给出题目来源与权利声明（或者只登记官方外链），禁止先复制第三方题干到公开 repo。
2. 审核原题内容与标准答案：必要时用符号运算/数值抽查，但不取代数学论证。
3. 提交知识节点的 top-1 / 辅助标签及其解释，区分人工审核和模型建议。
4. 定义题型与策略、错误模式和难度**来源**。
5. 二审复核关键公式、边界情形；完成后进入发布清单。
6. 每次更正必须回溯影响的教案包、学习路径和搜索索引。

## 4. 提议的题目评价细则

| 检查项 | 记录 |
|---|---|
| 题意完备性 | 已检查条件与量词、图示及引用 |
| 答案正确性 | 推导步骤、替代解、边界值及单位 |
| 关联正确性 | 知识点是否真正必要，还是仅包含同名词 |
| 教学价值 | 题目目标、典型误区、适合的学习阶段 |
| 使用合法性 | 原创权利或书面授权，第三方图片/图表单独审核 |
| 试卷属性 | 出自官方原卷/模拟题/原创，不能互换 |

**验收目标（非现状）**：每个正式公开的习题有完整来源/权利决策和答案审定；抽样多位教师一致性评价，训练集标签与评测数据分离。

## 5. 建议数据示例

~~~yaml
topic: derivatives/monotonicity
questionFormat: short_answer
knowledgeMappings:
  - topicId: historical-or-new-stable-id
    role: primary
    reviewStatus: teacher_review_required
solutionMethod: [function_monotonicity, classification_by_cases]
difficulty:
  level: unknown
  estimatedBy: null
rightsDecision: not_established
publish: false
~~~

上述 YAML 是设计示例，不能直接通过当前正式 JSON Schema 发布。真实标签请以当前 content/v1.3/mathematics-taxonomy.json 和后续正式数据契约为准。
