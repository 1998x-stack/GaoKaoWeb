# V1.3 测试体系、独立评估与发布门槛

> 状态：当前 CI 有语法检查、单测、静态页面检查、PDF 缓存独立核验；以下 V1.3 新功能测试多为**目标**，请按证据写入各版本 Release Report。

## 1. 现有可复现的检查（已实现）

- Node 内置测试：V1.0–V1.2 递归数据、知识关联、搜索排序、学习状态。
- 证据治理：11 PDF 哈希、页码缓存与 Poppler 文本逐节点核验；已实现 116 匹配节点、134 页码候选。
- 静态输出检查：页面内部链接、源文件版本一致性、主题路由、搜索映射与关系有效性。
- V1.3 metadata seed：5 条候选，published=0、mode=external_link_only，权限门禁单测。
- 目前**没有**完整真实浏览器 HTTP E2E、公共真题质量验收、教师备课任务测试或完整 AI 评测。不要通过看起来很全面的测试文件名替代真实验收报告。

## 2. 隔离测试运行器

| 层 | 责任 | 推荐工具 | 阻断条件 |
|---|---|---|---|
| L0 静态分析 | JS 语法、JSON Schema、文档链接 | node --check、AJV（如以后添加）、脚本 | 失败则阻断 |
| L1 单元测试 | 来源、版权判定、数学题型规则、状态迁移 | node:test | 失败则阻断 |
| L2 数据契约 | 引用 ID 唯一、地区/年份完整、许可证范围、撤回传播 | Schema + graph integrity | 不合法记录阻断 |
| L3 构建 | 所有 HTML 资源/相对链接/PDF hash/来源快照 | npm run build/check | 失败则阻断 |
| L4 真实浏览器 | 知识详情/搜索/收藏、教学包/练习/合法导出 | Playwright on GitHub-hosted runner | 上线前必须通过 |
| L5 可访问性/性能 | 键盘 + 人工抽样 + axe/Lighthouse | 自动+人工 | 高优先级缺陷阻断 |

CI 应从 checkout 后的干净目录执行，不能把本地手工生成的 dist 作为唯一证明。禁止删除失败的验收门槛来获得“全绿”。

## 3. 独立内容评估器（与测试运行器不同）

- 来源复核：审计者按 URL/官方真实标题/文件版本/页码与地区重新检查。
- 版权复核：权限人审查 grant、授权期限、第三方素材与衍生权。
- 数学正确性：具资质学科复核者判断条件、符号、证明、答案、范围和多解问题。
- 知识图：教师标注的题型与先修边与模型候选分开评价，冲突需仲裁。
- 中文搜索：建立不与构建种子重合的查询黄金集，评价 Recall@10、nDCG@10、失败案例。
- AI 结果：证据真实性、无依据拒答、数学推导、伪造引用与版权越权攻击用独立打分器与人工复查。LLM Judge 不是最终证明。

## 5. 典型对抗回归

1. 只存在“2025 上海数学试卷官方点评” → 不可将其展示为“2025 上海数学原卷”。
2. 来源 URL 是 https://moe.gov.cn.evil.example → 必须拒绝作为官方来源。
3. 本地 2019 年 PDF 页码匹配 → 不能标记已与官方原件逐页核验。
4. 许可只有 display_full，没有 distribute → 浏览可用，导出被禁止。
5. CC BY-ND 类型的资源被要求修改 → 需阻断未经许可的改编。
6. 已撤回版权的资源 → 搜索、页面、导出和 AI 索引必须移除。
7. 数学存在斜率为零/无定义、退化参数、分母为零等边界 → 解答需包含必要条件。
8. 只点了“我已阅读” → 不得算考试掌握度或测验成绩。
9. AI 引用了不存在的 PDF 第 20 页 → 校验器阻断引用。
10. HTTP 页面离线时，学习进度仍需优雅降级；不能泄露敏感学习记录。
