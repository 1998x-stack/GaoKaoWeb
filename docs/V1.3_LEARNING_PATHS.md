# V1.3 学习路线与复盘设计

状态：V1.2 已有本地“已阅读”和收藏；**独立学习路线、诊断和掌握度计算尚未实现**。本文件是 V1.3.3 的教学设计和数据规范。

## 1. 核心原则

- “读过 / 已收藏 / 能独立答题 / 在延迟测试仍正确”是四种不同事件。
- 学习路径的先修依赖需要教研审核；V1.2 title_similarity **不是先修证据**。
- 学习路线必须绑定课程版本、学习者目标、年级与适用地区；未知地区应提示，不推断考试卷别。
- 成绩、个人诊断和未成年人数据默认只存在浏览器，未来账号系统必须另做最小化、同意、权限及删除/导出设计。

## 2. 目标用户与入口

- 自主学生：选择目标专题和已有基础 → 1 次轻量诊断 → 专题链 → 练习 → 复盘。
- 教师：选择教学目标 → 确认先修知识 → 生成班级通用的匿名练习链（不上传学生个人身份）→ 课堂观察。
- 复习用户：根据此前**真实练习证据**推荐复习，而非单凭打开页面次数推断遗忘。

## 3. 领域模型

~~~text
LearningPath
 ├─ profile: grade, courseVersion, region, target, targetDate?
 ├─ units[]
 │    ├─ topicIds[]                    # stable FK
 │    ├─ prerequisites[]               # 教研审核的有向边
 │    ├─ objectives[]                  # 可观察行为
 │    ├─ authorizedQuestions[]
 │    ├─ entryCheck / exitCheck
 │    └─ reviewRules
 ├─ publicationStatus
 ├─ evidenceVersion
 └─ pedagogicalReviewer
~~~

单元应采用 immutable ID + version，避免修改专题标题破坏学习记录。不可把 2019 年历史理科/文科科目自动作为现行新高考课程体系。

## 4. 五阶段学习循环

1. **起点诊断**：概念题与代表性方法题，区别“不会”“不确定”“猜对”；不适合公开存储可识别个人答案。
2. **先修补齐**：先修图应是教师审核 DAG；未审核候选边不进入自动派课。
3. **方法讲解**：概念、动机、典型反例、可合法展示的原创/授权例题。
4. **形成性检测**：题目与知识点、错误模式、答题方式相关联；解法审核后才用于评价。
5. **复习与迁移**：根据可靠练习结果和间隔安排复习；允许用户调整或跳过，不将算法决策变成强制路线。

## 5. 数学试点路线

### 导数：入门 → 提升 → 综合

函数与变化率 → 导数符号与单调性 → 极值/最值 → 含参数分类 → 函数零点与不等式。先修边需核验具体课程版本。

### 圆锥曲线

解析几何与方程 → 联立与根的存在条件 → 韦达与弦长 → 定点/定值 → 参数与优化。先修边区分数学必要性与教师建议顺序。

### 三角函数

弧度与基本函数 → 图像/周期/对称性 → 恒等式 → 三角形解法 → 建模。课程方案可能不同，应单独记录适用性。

## 6. 学习状态机（拟议）

~~~text
not_started --open--> exploring
exploring --self_mark_read--> read
exploring/read --practice_validated--> evidence_of_understanding
evidence_of_understanding --delayed_check_pass--> retained
any --restart/review--> exploring
~~~

不能用 quiz 单次正确直接确定“掌握”。任何 masteryScore 应注明估计方法、答题样本、时间、置信边界和可解释性；V1.3 初期不需要数值掌握评分。

## 7. 流程和回归测试

- 拓扑排序、循环依赖检测、孤立目标检测。
- 每个资源关联可用的 reviewed/authorized Question；撤回必须同步阻断路径和导出。
- 诊断题、阶段题和复习题去重，禁止向学生透露内部参考评分。
- 从 V1.2 迁移只保留 bookmarks/read/recent，不暗中提升为 mastery。
- 回滚可复现旧版路径的节点和题目版本，仍不得恢复已撤回题目。
- 动态路线后续需做可访问性、移动端、省份跨年份适用性和隐私 E2E。

## 8. 提议验收标准

成功发布的每条路线：100% 有教师批准的先修边、可解析的稳定 topic ID、有效的题目授权和清晰目标。学习路线不会声明学生成绩提升、能力诊断准确率或 AI 个性化效果，直到有真实对照评测证据。
