# V1.3 数据词典与实体契约

状态：**规范性设计**。当前代码真正执行的是 schemas/v1.3/resource.schema.json 和 src/resources/rights-policy.mjs；本文件部分目标字段尚未落地，不能把“拟建”误称已实现。

## 1. 统一 ID 和版本策略

- Source: src_{issuer}_{publicationDate}_{digest}，定位来源网页或合法可用的原始文件。
- Resource: res_{ULID}，独立于标题与 URL；不同类型资源不可共用 ID。
- Question: q_{ULID}，同一道题多个题干修订记 QuestionVersion；来源版本与题目版本分别保存。
- KnowledgeTopic: 历史节点引用现有 V1.2 id，未来应维护 stableTopicId 与旧 id 的 aliases，不允许随目录移动随意更新外键。
- Curriculum: curriculum_{issuer}_{revision}，必须明确发布/生效日期及教学适用范围。
- RightsGrant: rg_{ULID}，授权主体、动作、地域、期限与具体受保护内容关联。
- EvidenceSpan: ev_{resourceId}_{hash}，原文定位仅在许可证允许时持久化。
- TeachingPack: pack_{ULID}；LearningPath: path_{ULID}；ReleaseSnapshot: rel_{commit}。

建议全部使用不可变资源 ID；标题、路径、来源站点 URL 均不是主键。

## 2. 实体字段

| 实体 | 必要属性 | 约束 |
|---|---|---|
| SourceRecord | sourceId, issuer, sourceUrl, resourceKind, publishedAt, visitedAt, authenticityStatus, scope | 官网网页存在不能代表本地 PDF 同一性 |
| Resource | resourceId, kind, sourceId, title, workflowStatus, latestVersion, rightsDecisionId | publicStatus 单独计算 |
| RightsGrant | owner, proofUrl, license, actions, validFrom, validTo, useRegion, reviewer, thirdPartyAssets | 默认不授予展示/导出/AI 权限 |
| ExamPaper | examYear, province, scheme, subject, paperName, examDate, officialQuestionSetProof | 只可在 verifiedAspect 为正式原卷时标注“真题” |
| Question | qid, version, authorOrPublisher, prompt, answer, reasoning, topicMappings, proofStatus | 题干只有获许可托管时出现 |
| TopicMapping | questionId, topicId, relationType, suggestScore, reviewStatus, reviewer | suggestScore 不是事实；须附审核 |
| TeachingPack | audience, objectives, durationMinutes, resourceRefs, teachingStages, attributionFooter, exportPolicy | 执行 export 时重新核权 |
| LearningPath | profile, entryCheck, units, prerequisiteEdges, exitCheck, spacedReview | 必须检测 DAG，不能默认“阅读=掌握” |
| EvidenceSpan | sourceHash, rightsGrant, locator, reviewStatus, reviewedBy, reviewedAt | 未人工确认不得作为官方引文 |
| AuditEvent | actor, changedAt, beforeHash, afterHash, action, reason, reviewer | 事件只追加，撤回即时生效 |

## 3. Resource（目前已落地字段）

来自 content/v1.3/source-candidates.json：

| 字段 | 类型 | 含义 |
|---|---|---|
| id / title / kind | string | 候选资源唯一 ID、标题、明确的资源类别 |
| provider / sourceUrl | string | 发布主体与来源 URL，URL 不等于正文使用许可 |
| publishedAt / issuedAt | date 或 null | 网页公布日与原文件发文日，分开记录 |
| year / provinceCodes / examScheme | int/null、string[]、string | 某项资料的年份和地域信息；空数组不是“全国适用” |
| verifiedAspect | string | **具体核验对象**，例如 official_review_not_exam_original |
| workflowStatus | enum | candidate → reviewed → published / withdrawn |
| scopeStatus | string | 描述所能证明的适用范围 |
| topicIds | string[] | 当前 seed 为空，不能声称已经映射到历史知识点 |
| usage.mode | external_link_only / hosted | 仅外链还是允许托管内容 |
| usage.rightsStatus | enum | not_established、licensed、author_owned、permission_in_writing、revoked |
| usage.grantedActions | enum[] | display_full, host_file, distribute, adapt, create_embeddings, send_to_external_llm |

当前 validateResource 对基础字段/授权做约束；**尚不等于外网可用性验证、版权律师审定、教师解答审核或完整 JSON Schema 验证**。它并未对所有未来题目字段建立严密的静态 schema。

## 4. 许可判断矩阵（目标规则）

| 动作 | 所需证据 |
|---|---|
| 官方链接 | URL/类型/发布主体确认即可；不包含全文 |
| 站内题干展示 | 独立 display_full 授权及内容审核 |
| 自建 PDF / 分发文件 | distribute 与必要的 host_file 授权 |
| 改编、变式、翻译 | adapt + 具体许可条件（例如 ND 禁止改编） |
| 全文搜索索引 | 需确认索引、缓存、摘要的许可证条款 |
| 向外部模型发送内容 | create_embeddings / send_to_external_llm、数据处理协议、隐私合规 |
| 教师导出习题包 | 每一资源的 distribute 权与署名等义务均满足 |

## 5. 版本迁移与引用

绝不可直接覆盖已发布题干；建立 Revision，保留 diff、hash、原始证据、审批记录，发布新版本后保留稳定 URL 与更正说明。真实原卷修订要明确“录入纠错”与“原卷被官方修订”的区别。历史节点 ID 改动需 alias 映射表和 301/HTML 静态重定向，不能丢失收藏夹与学习路线引用。

## 6. 示例约束（伪记录，仅作设计说明）

~~~json
{
  "kind": "authored_question",
  "sourceVerification": "author_confirmed",
  "examProfile": {
    "examYear": null,
    "provinceCodes": [],
    "scheme": "not_applicable"
  },
  "status": "review_required",
  "rights": {
    "canDisplay": false,
    "canDistribute": false,
    "canSendToLLM": false
  }
}
~~~

这是一种未来业务结构示意，不是当前 schema 的合法可直接入库记录；不要以示例绕过审核。
